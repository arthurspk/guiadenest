# Como contribuir com o Guia de NestJS

Obrigado por querer melhorar este guia! Ele só existe por causa da comunidade.

## Sugerindo um novo recurso

Abra uma [issue usando o template "Sugestão de recurso"](https://github.com/arthurspk/guiadenest/issues/new/choose) com:

- **Nome** do curso, canal, livro, ferramenta ou site
- **URL** funcionando (retornando HTTP 200)
- **Categoria** onde ele deve entrar (ex.: Cursos gratuitos, Ferramentas, Livros)
- **Por que incluir**: uma frase explicando o valor do recurso

### Critérios de aceitação

- O link precisa estar **funcionando** (sem erro 404, sem redirecionamento para página genérica).
- O conteúdo precisa ser **legal**: nada de material pirateado, cursos pagos redistribuídos sem autorização, PDFs de livros protegidos ou "drives" de terceiros.
- Recursos pagos são bem-vindos, desde que a descrição deixe isso claro.
- Prioridade para conteúdo em **português** e **gratuito**, mas referências em inglês de alta qualidade também entram.
- Cada item precisa de uma linha de descrição objetiva.

## Reportando um link quebrado

Abra uma [issue usando o template "Link quebrado"](https://github.com/arthurspk/guiadenest/issues/new/choose) informando o link, a seção onde ele está e, se souber, uma sugestão de substituto.

## Enviando um Pull Request

1. Faça um fork do repositório e crie uma branch a partir da `main`.
2. Edite o `README.md` (a fonte é sempre o português).
3. Verifique que todo link novo responde HTTP 200 antes de abrir o PR.
4. Descreva no PR o que foi adicionado, alterado ou removido e por quê.
5. Preencha o checklist do template de PR.

## Política de tradução

Este repositório não mantém mais uma tradução paralela em outro arquivo — o README em português é a única fonte oficial de conteúdo.
